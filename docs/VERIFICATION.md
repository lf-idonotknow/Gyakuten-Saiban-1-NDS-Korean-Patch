# 검증 정보와 세이브 안내

## 기준 파일

- 개발 기준: `r117`
- 파일 크기: `134,217,728`바이트
- SHA-256: `1bd9b6e1c89175c7c1538958a6469f1ecb05c0a71751d3a9b8802ce2c1331873`
- 공개 버전: 미정
- BPS와 배포 ZIP: 제작 전

원본과 결과의 식별 정보는 [manifest.json](../manifest.json)에 기록했습니다. BPS 적용 결과가 기준 파일과 전체 바이트까지 같은지 확인하는 검사는 배포 패치 제작 후 진행합니다.

## 닌텐도 DS 실기

2026년 11월 16일, 제작자가 직접 다음 결과를 확인했습니다.

- 보유한 닌텐도 DS 기기 3개, 플래시카드 3개, microSD 카드 3개에서 구동 성공.
- 이전에 문제가 있던 SD카드는 macOS가 생성한 파일 등을 정리하고 Windows에서 ROM을 복사한 뒤 정상화.
- 일시적인 불안정이었는지, 부가 파일이나 복사 과정이 영향을 주었는지는 미확정.

이는 제작자의 실기 확인 보고입니다. 27개 조합을 모두 시험했다는 의미는 아니며, 이 구동 보고에 전편 완주 확인은 포함되어 있지 않습니다. 이전의 흰 화면·오프닝 뒤 정지 보고보다 위 최신 결과를 현재 상태로 삼습니다.

## 로컬 실행 검사

같은 SHA-256의 r117을 에뮬레이터에서 실행해 제1화 첫 대화 진입, 법정 기록 열기·닫기, 다음 대사 진행을 확인했습니다. SD카드에서 복사한 실행 프로그램을 사용하는 로컬 검사에서도 같은 구간을 진행했습니다.

이 검사는 해당 구간의 실행 결과이며 모든 에피소드와 분기를 완주한 검사는 아닙니다.

## 세이브

- 개인 세이브나 세이브 스테이트는 배포하지 않습니다.
- 기존 세이브는 먼저 사본을 만들어 보관해 주세요.
- 로컬 검사에서 일부 기존 게임 내 세이브의 불러오기와 대사 진행을 확인했습니다.
- 모든 과거 개발판·일본판·플래시카드·에뮬레이터 사이의 세이브 호환성을 일괄 보장하는 결과는 아닙니다.
- ROM과 세이브의 기본 파일명 및 저장 위치는 사용 중인 실행 환경의 규칙을 따라 주세요.
