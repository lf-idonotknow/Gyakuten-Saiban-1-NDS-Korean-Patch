# 0.9.1 검증 정보와 세이브 안내

## 구동 확인

- <strong>0.9.1 / melonDS:</strong> 배포 BPS를 일본판 원본에 적용한 ROM을 처음부터 실행하여, 제1화의 얏파리 설명 두 줄과 앞뒤 대사가 정상적으로 표시되고 진행되는 것을 확인했습니다.
- <strong>0.9.0 / 닌텐도 DS 실기:</strong> 2026년 11월 16일, 제작자가 보유한 기기 3개·플래시카드 3개·microSD 카드 3개에서 구동 성공을 확인했습니다. 27개 조합을 모두 시험했다는 의미는 아닙니다.
- <strong>0.9.1의 닌텐도 DS 실기 재확인은 아직 하지 않았습니다.</strong>

위 실행 구간의 확인은 전편의 모든 분기를 다시 플레이한 결과와 구분합니다.

## 0.9.1 수정 확인

초반 얏파리 설명 대사가 둘째 줄에서 시작하여 마지막 줄이 화면 아래에서 잘리던 문제를 수정했습니다. 대사의 내용은 유지했습니다.

전체 29,866개 대사의 실제 제어명령을 검사하여, 같은 글자 위치에서 페이지 넘김 뒤에 줄바꿈이 중복 실행되는 사례가 수정 전 1곳에서 수정 후 0곳으로 줄어든 것을 확인했습니다. 수정 장면 앞뒤의 화면은 기존과 동일하며, 글꼴과 그래픽도 유지했습니다.

## 배포 패치 무결성

- 지원 원본: Nintendo DS 일본판, 게임 코드 `AGYJ`, 리비전 `0`
- 원본 크기: `67,108,864`바이트
- 결과 크기: `134,217,728`바이트
- 원본과 결과의 확인값: [README](../README.md#준비물과-적용-대상), [manifest.json](../manifest.json)
- 0.9.1은 전체 한글화를 포함한 독립 패치입니다. 0.9.0 이용자도 <strong>일본판 원본에 적용</strong>합니다.
- Floating IPS로 BPS를 다시 적용하여 검증한 수정 ROM과 <strong>전체 바이트 및 SHA-256 일치</strong>를 확인했습니다.
- 안내에 사용하는 <strong>Rom Patcher JS</strong>에서도 원본과 BPS를 선택하여 적용하고, 내려받은 ROM의 전체 바이트 및 SHA-256 일치를 확인했습니다.
- 같은 크기라도 내용이 다른 원본은 체크섬 오류로 적용이 거부되는 것을 확인했습니다.
- ZIP 내부 파일과 확인값을 검사하고, ZIP에 포함된 BPS로도 동일한 ROM이 만들어지는 것을 확인했습니다.

## 세이브 안내

기존 세이브는 먼저 별도로 백업해 주세요. ROM과 세이브의 기본 파일명, 확장자, 저장 폴더는 사용 중인 플래시카드·에뮬레이터의 규칙을 따릅니다.

0.9.0에서 일부 기존 게임 내 세이브의 불러오기와 진행을 확인했습니다. 서로 다른 패치 버전과 실행 환경 사이의 세이브 호환성 전체를 확인한 결과는 아닙니다. 다른 환경의 세이브는 확장자만 바꾸기보다 해당 환경이 안내하는 변환 방법을 따라 주세요.
